# Pride · Creamfields · Noche de Museos

Sitio estático para GitHub Pages.

## Cómo publicarlo
1. Sube todo el contenido de esta carpeta (index.html, css/, js/, assets/, fonts/) a la raíz de un repositorio.
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`.
3. El sitio queda en https://USUARIO.github.io/REPOSITORIO/

## Páginas
- Inicio: `index.html`
- Pride: `index.html#pride`
- Creamfields: `index.html#creamfields`
- Noche de Museos: `index.html#museos`
